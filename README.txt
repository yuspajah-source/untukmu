WEBSITE UNTUK ABIRA LUCKYSHA PUTRI

Cara menjalankan:
1. Ekstrak folder project.
2. Masukkan file musik MP3 milikmu ke:
   assets/musik/M1.mp3
3. Buka index.html di browser, atau jalankan dengan ekstensi Live Server di VS Code.

Struktur:
- index.html
- style.css
- script.js
- assets/musik/M1.mp3  (masukkan file musik sendiri)

Catatan:
- Musik mulai saat tombol "Mulai" ditekan karena browser biasanya membatasi autoplay.
- Jika musik belum terdengar, pastikan nama file tepat M1.mp3 dan lokasinya benar.
- Teks ucapan dapat diubah langsung pada bagian <p class="message"> di index.html.
